Privacy Policy

Last updated: November 9, 2026

my-uploader is a personal tool that runs on its owner's own computer. It does not operate a website backend or database and does not collect, sell or share personal data with any third party.

Data handled

When the owner authorizes the tool through TikTok Login Kit, TikTok provides an access token. The token is stored only in a local file on the owner's computer and is used only to upload videos to the owner's own account.

Retention and deletion

The owner can delete the local token file at any time and can revoke the app's access from the TikTok app settings.
